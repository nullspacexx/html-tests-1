Обо мне

С детства интересовалась технологиями, программированием и устройством цифровых систем. Умеет анализировать проблемы, находить нестандартные решения и работать с большими объёмами информации.

В свободное время изучает новые технологии, экспериментирует с интерфейсами и совершенствует собственные проекты.

Профессиональные навыки

  • HTML — создание структуры веб-страниц.
  • CSS — оформление и стилизация интерфейсов.
  • JavaScript — добавление интерактивности.
  • Работа с DevTools.
  • Поиск и исправление ошибок.

Мои проекты

  1. Magix Portal — информационный портал для жителей Магикса.
  2. Zenith Control — веб-интерфейс для мониторинга цифровых систем.
  3. Pixie Network — платформа для общения и обмена информацией между пикси.
